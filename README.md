# ZoneScout

Private Telegram bot that analyzes MT5 chart images to mark supply/demand zones, key levels, and deliver labelled charts plus concise 2:1 RR trade ideas and explanations.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
